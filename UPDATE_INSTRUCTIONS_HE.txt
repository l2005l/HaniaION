HaniaION - שדרוג התראות חוצה פלטפורמות
================================

ענף יעד: feature/final-ui

מה תוקן:
- תוקנה שגיאת HTTP 500 בתזמון התראות K-69.
- מפתח VAPID נטען כאובייקט חתימה תקין במקום להישלח כטקסט PEM.
- כשל בשליחת Push מטופל בלי להפיל את השרת בשגיאת 500 לא מוסברת.
- נוסף פרויקט Android מקורי עם תזמון מקומי גם כשהאפליקציה סגורה.
- נוסף מסלול iPhone/iPad באמצעות התקנה למסך הבית ו-Web Push.
- נוספו הודעות מדויקות לפי סוג המכשיר במקום הודעת "דפדפן לא תומך" כללית.

העלאה דרך GitHub:
1. פתח את המאגר l2005l/HaniaION.
2. ודא שאתה נמצא בענף feature/final-ui.
3. העלה את כל הקבצים והתיקיות מתוך ה-ZIP, תוך החלפת הקבצים הקיימים.
4. כתוב הודעת Commit כגון: fix K69 VAPID signer HTTP 500
5. המתן לסיום Preview Deployment של Render.
6. פתח את התצוגה המקדימה ולחץ שוב על תזמון ההתראות למחזור הבא.
7. לבניית APK: פתח Actions, בחר Build Android APK והורד את HaniaION-Android.

הערה על static/app-release.apk:
הקובץ הקיים במאגר הוא ה-APK הישן ואינו כולל את גשר ההתראות החדש. אין להפיץ
אותו כגרסה 3.0. לאחר בדיקת ה-APK שנוצר ב-Actions, ניתן להחליף אותו בקובץ החדש.

חשוב:
- אין ב-ZIP סיסמאות או משתני סביבה של Render.
- אין צורך לשנות כרגע את VAPID_PUBLIC_KEY או VAPID_PRIVATE_KEY.
- תיקוני main הנפרדים אינם כלולים בקובץ הזה.
